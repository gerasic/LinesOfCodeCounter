# LinesOfCodeCounter

Консольная утилита на Java для подсчёта строк в файлах по указанному пути. Игнорирует пустые строки и строки, содержащие только пробелы.

## 📚 О проекте

Учебный проект, созданный для изучения основ Java:
- Работа с консольным вводом
- Чтение файлов и обход директорий
- Фильтрация данных
- Базовая структура Java-программы
- Практика объектно-ориентированного подхода
